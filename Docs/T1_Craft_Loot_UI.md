# T1 — крафт, добыча, склад, дроп, маг, UI

Спека среза. Не заменяет GDD. Числа — стартовые, крутим балансом.

**Уже есть:** хотбар 9 + сумка 27, сундук `StorageContainer` (E), кирка → камень с обломков, дроп в мир, вражеский маг (убить), свой маг (визуал).

**Срез закрывает:** дерево, нормальный склад, таблицы лута, свой маг как станция, крафт L1, отдельные канвасы с одной схемой управления.

---

## 1. Ресурсы T1

| Id | Где берём | Куда |
|----|-----------|------|
| `wood` | рубка деревьев | крафт L1, модули |
| `stone` | кирка (обломки, камень поселения) | ремонт, база, крафт |
| `ore` | кирка / модули замка | плавка → `metal` |
| `metal` | плавка руды; дроп модулей | оружие, броня, турели |
| `chronum` | **только** вражеский маг / босс | корм мага, телепорт |
| блюпринт | сундук / элита / маг | разлок рецепта, не стак в кармане как «меч +5» |

Карман не бесконечный. Излишек → склад замка. Хронум в инвентаре рыцаря, пока не скормлен магу.

## 2. Добыча дерева

Террейн уже с прототипами в `Assets/Trees/`.

- Цель: дерево на террейне = ломаемый объект (кирка / топор позже; **T1 = кирка**).
- HP ~3–4 удара. Падает `wood` ×2–4 в мир (тот же `WorldLootPickup`).
- Пень остаётся или меш скрывается; респаун вместе с поселением / сменой ноды — не сразу под ногами.
- Своя площадка замка: деревья на паде **не** фармятся (или 0–2 декоративных без лута), чтобы не сидеть AFK у дома.

Камень — как сейчас: кирка по обломкам / породам → `stone`.

## 3. Склад

Два слоя, не три.

| Слой | Слоты | Где | Зачем |
|------|-------|-----|--------|
| Рыцарь | 9 хотбар + 27 сумка | на персонаже | рейд и фарм |
| Склад замка | **36** (модуль «Склад» в wall-слот) | свой замок | запас T1 |

Сундук поселения — лут, не второй дом. Открыл → забрал → закрыл.

**Правила склада**

- E в радиусе ~3 м, курсор свободен.
- Одна сетка: слева склад, справа хотбар+сумка (как сундук сейчас, но крупнее).
- Shift+клик = перекинуть стак целиком.
- Модуль сломан → содержимое высыпается в мир (уже так в `StorageContainer`).
- Без модуля «Склад» — только карман рыцаря (ранний гейм жёсткий).

T1: **один** склад на замок. Второй слот склада — не в этом срезе.

## 4. Дроп

Всё падает **в мир** (подбор пробел/радиус как сейчас). Не в автолут инвентаря с 20 метров.

### Враги (шар / камень)

| Что | Шанс | Кол-во |
|-----|------|--------|
| `stone` или `wood` | 70% | 1–2 |
| `ore` | 20% | 1 |
| ничего | 10% | — |
| блюпринт Common | 3% | 1 |

Без оружия в дропе. Без хронума.

### Модули вражеского замка

Снести сегмент / отбить киркой обломок:

| Модуль | Дроп |
|--------|------|
| Стена / дверь | `stone` 2–4, редко `ore` 1 |
| Спавнер | `ore` 2–3 + шанс Common-блюпринта 8% |
| Башня | `metal` 1–2 + `ore` 1–2 |
| Склад врага | то, что внутри + `wood`/`stone` |

Свой замок игроку не дропает «награду за гриф».

### Вражеский маг

Гарантированно:

- `chronum` × **3** (T1)
- 1 блюпринт **не ниже Uncommon** (если пул пуст — `metal` ×5)

Плюс взрыв/обломки как сейчас. Хронум — отдельный визуал (не камень).

## 5. Свой маг (взаимодействие)

Не бьём. **E** у MagеHeart.

Панель мага:

1. **Хронум** — полоска «сытость» + кнопка «Накормить» (тратит хронум из инвентаря).
2. **Телепорт** — список открытых нод (позже); без сытости — серое.
3. **Апгрейд мага** — один ряд T1.

### Апгрейд T1 (один уровень за срез)

| Уровень | Стоимость | Эффект |
|---------|-----------|--------|
| 0 (старт) | — | сытость падает медленно, телепорт дорогой |
| 1 | `chronum` 5 + `metal` 8 | +макс. сытость, −цена телепорта **или** +радиус ауры ремонта (выбрать одно на реализацию: **ауры ремонта T1**) |

Повторный E закрывает. Пока открыто — оружие как у инвентаря (блок).

Вражеского мага не апгрейдим — только убиваем.

## 6. Крафт L1

Станция: модуль **Верстак** в wall-слот. E → канвас крафта.

Без верстака крафта нет (карманный крафт запрещён GDD).

Рецепты стартовые (все Common, без блюпринта):

| Рецепт | Вход | Выход |
|--------|------|-------|
| Доски (пакет) | wood 4 | `plank` 2 (если не хотим отдельный id — wood тратится на модули напрямую; тогда эту строку выкинуть) |
| Слиток | ore 3 | metal 1 (плавильня; если плавильни нет в T1 — верстак варит 1:4 медленнее) |
| Болты (пачка) | metal 1 + wood 1 | расходник арбалета ×12 |
| Ремонтный набор | stone 4 + wood 2 | 1 заряд ремонта модуля (или мгновенный хил сегмента у верстака) |

За блюпринтом (лут):

| Рецепт | Вход | Выход |
|--------|------|-------|
| Броня T1 | metal 6 + wood 4 | слот брони (один комплект) |
| Запасной посох / ап арбалета | metal 5 + chronum 0 | не хронум в крафте оружия |

**Правило:** хронум не входит в рецепты рыцаря T1, только маг и телепорт.

Крафт: выбрать рецепт → видно хватает/нет → Hold или кнопка «Создать» → предмет в сумку, иначе на склад если сумка полная.

## 7. UI — одна схема на все панели

Все «большие» окна — **один предок** `GameUI`, стиль пергамент как хотбар.

### Канвасы (слои)

| Канвас | Когда | Сорт |
|--------|-------|------|
| HUD | всегда в игре | HP, мана, хотбар, прицел, подсказка E |
| Inventory | I | сумка + хотбар крупно |
| Storage | E у склада | склад ‖ инвентарь |
| Craft | E у верстака | рецепты ‖ инвентарь |
| Mage | E у своего мага | сытость, корм, апгрейд |
| Prompt | рядом с интерактивом | одна строка: `E — Склад` |

Одновременно **не больше одного** модального (Inventory / Storage / Craft / Mage). I или Esc закрывает текущее. Открыть склад при открытом крафте — сначала закрыть крафт.

### Управление (везде одинаково)

| Ввод | Действие |
|------|----------|
| E | открыть ближайшее (склад / верстак / маг / сундук) |
| I | инвентарь; повтор — закрыть |
| Esc | закрыть любое окно |
| ЛКМ | взять/положить стак (как сейчас) |
| RMB | половина стака |
| Shift+ЛКМ | быстрый трансфер в «другую» панель |
| 1–9 / колесо | хотбар, в меню не стреляем |
| Tab | в Craft/Mage — следующий блок (рецепты ↔ инвентарь / корм ↔ апгрейд) |

Курсор: в модалке виден; в HUD скрыт.

### Раскладка модалки (1920×1080)

```
┌─────────────────────────────────────────┐
│  Заголовок          [Esc закрыть]       │
│  ┌──────────────┐  ┌─────────────────┐  │
│  │ Контекст      │  │ Инвентарь       │  │
│  │ склад/рецепты │  │ хотбар снизу    │  │
│  │ маг-апгрейд   │  │ сумка сеткой    │  │
│  └──────────────┘  └─────────────────┘  │
│  Подсказка: Shift быстро · RMB половина │
└─────────────────────────────────────────┘
```

Контекст слева всегда «станция», справа всегда «ты». Не плодить уникальные сетки.

HUD: хотбар по центру низа; HP+мана слева (уже); справа позже — сытость мага (маленькая иконка), не второй здоровбар.

Подсказка E — над центром прицела, не в углу.
