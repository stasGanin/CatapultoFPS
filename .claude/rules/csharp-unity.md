# C# / Unity

## Стиль
- Современный C#; `var` только когда тип очевиден.
- Приватные `[SerializeField]` для проводки из инспектора; `public` только для настоящего API.
- `[Header]` / `[Tooltip]` — экономно, для неочевидных полей.
- Один публичный тип на файл, имя файла = имя типа.

## Жизненный цикл
- `Awake`: кешировать свои компоненты. `Start`: общаться с другими объектами.
- `OnEnable`/`OnDisable`: подписка/отписка всегда парой.
- `Update` тонкий: ввод → намерение → вызовы `Tick(dt)` у сфокусированных систем.

## Границы модулей
| Модуль | Владеет | Не владеет |
|---|---|---|
| Player | движение, прыжок, ground check | стрельба, UI |
| Camera | обзор, чувствительность | логика оружия |
| Weapons | выстрел, перезарядка, патроны, хитскан/снаряд | движение игрока |
| Health / Damage | hp, смерть, применение урона (`IDamageable`) | VFX |
| UI | привязка HUD к состоянию | правила игры |

- Логика прицела/попадания возвращает результат; VFX/аудио реагируют на него.
- UI и фидбек — через C# события, без циклических ссылок между MonoBehaviour.
- Класс > ~200 строк или 2 ответственностей → разделять на input / simulation / view.
- Общий код в `Core/`, только если им пользуются 2+ домена. Читы и оверлеи — в `Debug/`.
- Сеть/мультиплеер не добавлять до запроса, но не завязывать боёвку на синглтон.
- Новые состояния игры (меню, пауза, смерть) — только когда появляются реальные режимы.

## Надёжность
- Внешние ссылки проверять один раз при инициализации, дальше fail-fast.
- Слои/теги — через константы или сериализованные ссылки, не строки по коду.
- Raycast: именованные маски + комментарий, что они бьют и зачем.
- **Не добавлять новых** `FindObjectOfType`/`GameObject.Find` и `Resources.Load` по строке там, где можно сериализованную ссылку. Существующие — не трогать без задачи.

## Известный техдолг (не расширять, чинить только по задаче)
- Большие файлы: `CraftUI`, `EnemyRoller`, `EnemyUnit`, `BuildingPlacer`, `CastleWall`, `PreSlicedCastleWall`, `InventoryUI`, `PlayerInventory`.
- Враги (`EnemyUnit`/`Roller`/`Brute`/`Bomber`) дублируют поля и поиск целей; тюнинги в сериализованных float, конфигов врагов нет.
